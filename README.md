# 随手记

想记什么就写什么：一句话、一件事、买了多少钱。既当备忘录，也能看这个月花了多少。

网址：**https://aetherecho77.github.io/jizhang/**

## 装到手机上

**iPhone / iPad（用 Safari 打开）**
1. 打开上面的网址
2. 点底部「分享」按钮（方框带向上箭头）
3. 选「添加到主屏幕」

**安卓（Chrome 或自带浏览器）**
1. 打开网址
2. 点右上角「⋮」→「添加到主屏幕」/「安装应用」

装好后桌面上会出现橙色的「记」字图标，点开是全屏的，跟普通 App 一样。

## 怎么用

上面那个大框，想写什么写什么，然后点「记下来」。就这么简单。

**记账不用专门记**：只要句子里写了带单位的钱，「18块」「35.5元」这种，它自己会认出来、标成橙色，并算进本月花费。

**哪些不会被当成钱**：「3楼」「11点」这种没有单位的不认。所以写「3楼会议室 11点开会」是纯备忘，不会算进账。

- 「找一找」：输入一个字就能筛出相关的
- 「只看钱」：只看记过钱的那些
- 点任意一条 → 可以改，可以删

底部一直显示本月花了多少。

## 表格

顶部切到「表格」，就是一个真表格：日期 / 内容 / 金额 三列，从上往下按时间排。

- 点某一行，会回到「随手记」并把那条打开，方便改
- 下面「导出表格」会存一个 `.csv` 文件，手机上的 WPS、Excel 都能打开，也能打印

表格里的数据和「随手记」里是同一份，不是两套。记一条，两边都能看到。

## 数据存在哪

存在手机浏览器自己身上，不上传服务器，断网也能记。

- **没点「记下来」的字不会丢**：写到一半关掉，下次打开还在。
- **存一份**：右下角「存一份」导出一个文件，发到自己微信、存网盘都行。
- **恢复**：换了手机、清了浏览器数据之后，点「恢复」选那个文件，记录就回来了。**重复的会自动跳过**，不会变成两份；也不会删掉你手机上已有的记录。

**iPhone 上要注意**：连续 7 天以上不打开，系统可能清掉本地数据。所以 5 天没记，它会提醒你备份。安卓没有这个限制。

## 技术

单页 HTML + manifest + service worker，纯静态，托管在 GitHub Pages，零后端、零成本。
