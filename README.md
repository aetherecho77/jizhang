# 记账

给长辈用的极简记账。打开就记，不分类、不图表、不要账号。

网址：**https://aetherecho77.github.io/jizhang/**

## 装到手机上

**iPhone / iPad（用 Safari 打开）**
1. 打开上面的网址
2. 点底部「分享」按钮（方框带向上箭头）
3. 选「添加到主屏幕」

**安卓（Chrome 或自带浏览器）**
1. 打开网址
2. 点右上角「⋮」→「添加到主屏幕」/「安装应用」

装好后桌面上会出现橙色的「记」字图标，点开是全屏的，跟普通 App 一样。

## 怎么用

1. 输入金额
2. 想写一句就写（可不写）
3. 点「记一笔」

- 默认记支出；要记收入，先点上面那个「收入」
- 记错了，点右边「删」
- 底部一直显示本月花了多少
- 右下角「备份」可以导出一份文件

## 数据存在哪

存在手机浏览器自己身上，不上传服务器，断网也能记。

**一个要注意的地方**：iPhone 上如果连续 7 天以上不打开这个应用，系统可能把本地数据清掉。所以应用在 5 天没记的时候会提醒一句「备份」。安卓没有这个限制。

## 技术

单页 HTML + manifest + service worker，纯静态，托管在 GitHub Pages，零后端、零成本。
